# Smiley assets

`fluent-grinning-face-with-smiling-eyes.svg` is Microsoft's [Fluent Emoji “Grinning face with smiling eyes”](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Grinning%20face%20with%20smiling%20eyes/Color/grinning_face_with_smiling_eyes_color.svg), used under the MIT license in this directory.

Run `pnpm run generate-smiley-assets` to rebuild the color, light-mode grayscale and dark-mode grayscale 512 px PNGs consumed by the app.
